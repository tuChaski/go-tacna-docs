# Planificación

El cronograma detallado, con tareas y dependencias, se mantiene en [Planificacion_ProjectLibre_go-tacna.xml.pod](Planificacion_ProjectLibre_go-tacna.xml.pod). A grandes rasgos, el proyecto se organiza en seis fases:

- **Fase 1 — Preparación:** infraestructura, base de datos, estructura técnica y definición inicial; se obtiene la base lista para desarrollar.
- **Fase 2 — Diseño:** prototipos y validación de usabilidad; se obtiene una propuesta de interfaz revisada.
- **Fase 3 — Servicios:** API, autenticación y tiempo real; se obtienen los servicios principales del sistema.
- **Fase 4 — Aplicaciones:** mapas, GPS, app móvil y panel web; se obtiene una primera solución integrada.
- **Fase 5 — Validación:** pruebas funcionales, integración, usabilidad y campo; se obtiene una versión corregida y evaluada.
- **Fase 6 — Entrega:** despliegue, compilación Android y consolidación del informe; se obtiene la versión de entrega.
